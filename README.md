# Gallery App

Personal photo gallery app I built using React Native. Works on web, iOS and Android.

## What it does

- Login with Google
- Add photos with captions
- Voice input for captions (still working on this)
- Dark/light theme
- Works offline
- Share photos

## Built with

- React Native
- TypeScript
- Expo
- React Navigation
